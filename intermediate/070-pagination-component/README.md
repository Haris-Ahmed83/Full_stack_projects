# Pagination Component 🔢
> A robust and reusable web component for navigating through large datasets.

## Description
This project implements a dynamic and user-friendly pagination component designed to enhance data navigation in web applications. It effectively breaks down extensive lists or search results into manageable pages, significantly improving user experience and application performance. The component is built to be easily integrated and customized for various data display needs.

## Features
*   Dynamically generates page numbers based on total items and items per page.
*   Supports "Previous" and "Next" navigation buttons for intuitive browsing.
*   Highlights the currently active page for clear user feedback.
*   Handles edge cases gracefully, such as disabling navigation buttons on the first or last page.
*   Provides options for displaying a subset of page numbers (e.g., `1...5, 6, 7, 8...10`) for cleaner UIs.
*   Designed for reusability and easy integration into new or existing web projects.
*   Demonstrates integration strategies with API-driven data fetching for paginated content.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Pagination Logic:** Algorithms for calculating total pages, determining the range of items for the current page, and managing active page states.
*   **Page Numbers:** Dynamic generation, rendering, and event handling for clickable page number links.
*   **API Pagination:** Strategies for making requests to a backend API to fetch data for specific pages, handling parameters like `page` and `limit`.
*   **Navigation:** Implementation of "Previous", "Next", and direct page jump functionalities, including state management for navigation controls.
