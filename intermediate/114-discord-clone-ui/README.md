# Discord Clone UI 💬
> A modern and responsive user interface replicating the core elements of a Discord-like communication platform.

## Description
This project focuses on building the frontend user interface for a Discord clone. It meticulously recreates the familiar layout and interactive components, providing a robust foundation for a real-time communication application. The UI is designed to be intuitive and visually appealing, mirroring the user experience of popular chat applications.

## Features
*   **Server Sidebar:** Navigate between different servers effortlessly.
*   **Channel List:** View and select channels within a chosen server.
*   **Main Chat Area:** Display messages, user interactions, and system notifications.
*   **User List:** See active users and their statuses within the current channel.
*   **Message Input:** Compose and send messages with a rich text input area.
*   **Responsive Design:** Adapts gracefully to various screen sizes for a consistent experience.
*   **Interactive UI Elements:** Hover effects, active states, and clickable components for enhanced usability.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Channel List:** Implementation of a dynamic sidebar displaying various text and voice channels, with active state highlighting.
*   **Chat Area:** Construction of the main content pane for displaying messages, including user avatars, timestamps, and message content.
*   **User List:** Design of a right-hand sidebar listing online and offline users within the active channel.
*   **Message Input:** Creation of a persistent input field with styling for text entry and a send mechanism.
*   **Server Sidebar:** Development of the leftmost navigation bar for switching between different server contexts.
