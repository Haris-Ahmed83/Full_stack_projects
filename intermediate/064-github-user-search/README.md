# GitHub User Search 🔎
> A responsive web application to search and display GitHub user profiles.

## Description
This project is a responsive web application designed to search and display GitHub user profiles. Users can input a GitHub username to retrieve and view public profile information, presented in an easy-to-read card format. It demonstrates efficient data fetching from the GitHub API and robust state management for a smooth user experience.

## Features
*   Search for any GitHub user by username.
*   Display user avatar, name, username, bio, and key statistics (followers, following, public repositories).
*   Dynamic loading indicator for API requests.
*   Clear error messages for invalid usernames or API issues.
*   Responsive design for seamless viewing across various devices.
*   Direct links to the user's GitHub profile.

## Tech Stack
*   React.js
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   GitHub REST API

## Key Concepts Demonstrated
*   **API Fetching**: Utilizing the `fetch` API to retrieve data from the GitHub REST API.
*   **useState/useEffect**: Managing component state and handling side effects, such as data fetching and component lifecycle events.
*   **Loading/Error States**: Implementing clear UI feedback for users during data loading and when errors occur (e.g., user not found, network issues).
*   **Cards**: Presenting fetched user data in a well-structured and visually appealing card layout.
