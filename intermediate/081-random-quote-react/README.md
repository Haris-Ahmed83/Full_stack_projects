# Random Quote React 💬
> Generate and share inspiring quotes with a modern, animated user interface.

## Description
This project is a dynamic web application built with React, designed to display a variety of random quotes. It provides users with an engaging interface to discover new insights and easily share them across platforms. The application serves as an intermediate-level demonstration of integrating external APIs and applying key React hooks for state and lifecycle management.

## Features
*   Displays a new random quote and its author upon page load.
*   Allows users to fetch a new random quote with a single button click.
*   Includes functionality to share the current quote directly to social media (e.g., Twitter).
*   Incorporates subtle animations and transitions for a smooth user experience when quotes change.
*   Features a clean, responsive design that adapts to various screen sizes.
*   Utilizes an external API to source a diverse collection of quotes.
*   Provides clear visual feedback during loading states.

## Tech Stack
*   React
*   JavaScript
*   HTML5
*   CSS3
*   Fetch API

## Key Concepts Demonstrated
*   **Fetch API:** Asynchronously retrieving data from an external REST API to populate quotes.
*   **Sharing:** Implementing social media sharing capabilities to allow users to easily disseminate quotes.
*   **useState:** Managing component-specific state, such as the current quote, author, and loading status.
*   **useEffect:** Handling side effects like initial data fetching, re-fetching data on user interaction, and managing component lifecycle.
*   **Animations:** Enhancing user experience through CSS transitions and animations for quote changes and button interactions.

## Getting Started
To run this project locally:
1.  Clone the repository.
2.  Navigate to the project directory.
3.  Run `npm install` to install dependencies.
4.  Run `npm start` to launch the development server.
5.  Open your browser to `http://localhost:3000`.
