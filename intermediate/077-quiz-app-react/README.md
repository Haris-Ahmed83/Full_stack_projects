# Quiz App React 🧠
> Test your knowledge with this interactive and engaging quiz application.

## Description
This project is an interactive quiz application built with React, designed to challenge users with a series of questions and provide instant feedback. It demonstrates core React principles by managing application state, tracking user scores, and dynamically updating the UI based on user interactions and a countdown timer. This intermediate-level project is perfect for understanding fundamental React concepts in a practical context.

## Features
*   Engaging multiple-choice questions interface.
*   Real-time score tracking throughout the quiz session.
*   Dynamic display of questions and answer options.
*   Countdown timer for each question to add an element of challenge.
*   Instant feedback on correct/incorrect answers after selection.
*   Quiz completion screen showing final score and performance summary.
*   Option to restart the quiz for another round.

## Tech Stack
*   React
*   JavaScript
*   HTML
*   CSS

## Key Concepts Demonstrated
*   **State Management**: Handling the current question index, user's score, timer values, and overall quiz flow within React components using `useState` and `useEffect`.
*   **Scoring**: Implementing logic to calculate and display the user's score based on correct answers, updating the score dynamically.
*   **Conditional Rendering**: Dynamically displaying different UI elements (e.g., questions, answer options, results screen, timer) based on the current state of the quiz.
*   **Timer**: Integrating a countdown timer for each question to add a time-sensitive challenge, handling its start, pause, and reset.
