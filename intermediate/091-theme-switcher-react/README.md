# Theme Switcher React 💡
> A simple React application demonstrating a dynamic theme switching mechanism.

## Description
This project showcases how to implement a theme switcher in a React application. Users can toggle between different themes (e.g., light and dark mode), and their preference is persisted across sessions. It's an excellent example for understanding global state management with the Context API and dynamic styling with CSS variables.

## Features
*   Toggle between light and dark themes with a single button.
*   Theme preference is automatically saved using `localStorage`.
*   Global theme state managed efficiently with React's Context API.
*   Dynamic styling powered by CSS Variables for easy theme adjustments.
*   Intuitive and accessible toggle button for theme switching.
*   Responsive design ensures functionality across various device sizes.

## Tech Stack
*   React
*   JavaScript
*   HTML
*   CSS

## Key Concepts Demonstrated
*   **Context API:** Utilized for managing and providing the global theme state to components throughout the application, avoiding prop drilling.
*   **CSS Variables:** Employed to define and apply dynamic styles (colors, backgrounds, etc.) that change based on the active theme.
*   **localStorage:** Used to persist the user's chosen theme preference, ensuring it's remembered even after closing and reopening the browser.
*   **Toggle Button:** Implementation of a reusable UI component that acts as the primary interface for switching between themes.

## Getting Started
```bash
# Clone the repository
git clone https://github.com/Haris-Ahmed83/Theme-Switcher-React.git # (Adjust if your repo name is different)
cd Theme-Switcher-React

# Install dependencies
npm install

# Start the development server
npm start
```
This will open the project in your browser, typically at `http://localhost:3000`.
