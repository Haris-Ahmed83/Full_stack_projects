# Counter App React 🔢
> A simple yet effective React application to demonstrate fundamental state management.

## Description
This project is a basic counter application built with React, designed to showcase core React concepts in an interactive way. Users can increment, decrement, and reset a numerical count, providing a clear example of how to manage and update component state in a modern web application.

## Features
*   Increment the counter value with a dedicated button.
*   Decrement the counter value with a dedicated button.
*   Reset the counter to its initial state (zero).
*   Real-time display of the current counter value.
*   Buttons dynamically enable/disable based on count limits (e.g., cannot decrement below zero).
*   Clean and intuitive user interface.

## Tech Stack
*   React
*   JavaScript
*   HTML
*   CSS

## Key Concepts Demonstrated
*   `useState`: Utilized for managing the counter's numerical value, showcasing how to declare and update state variables within functional components.
*   `Event Handlers`: Implementation of functions triggered by user interactions (e.g., button clicks) to modify the component's state.
*   `Component State`: Demonstrates how a component's internal data (`count`) drives its rendered output and behavior, and how changes to this state re-render the UI.
*   `Conditional Rendering`: Applied to dynamically enable or disable buttons based on the current counter value, improving user experience and preventing invalid operations.

## Getting Started
To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Haris-Ahmed83/Counter-App-React.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Counter-App-React
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Start the development server:**
    ```bash
    npm start
    ```
    This will typically open the application in your browser at `http://localhost:3000`.
