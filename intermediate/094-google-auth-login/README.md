# Google Auth Login #94 🔑
> A secure web application demonstrating seamless Google authentication using Firebase.

## Description
This intermediate-level project showcases the implementation of Google authentication in a web application. It leverages Firebase Authentication to provide a robust and secure login system, allowing users to sign in with their existing Google accounts.

## Features
*   **Google Sign-In/Sign-Up:** Users can easily authenticate using their Google accounts.
*   **Firebase Authentication Integration:** Securely handles user authentication and session management.
*   **Popup-Based Authentication Flow:** Implements a user-friendly popup window for the Google sign-in process.
*   **User Profile Display:** Fetches and displays authenticated user's name, email, and profile picture.
*   **Logout Functionality:** Allows users to securely sign out of their session.
*   **Real-time Authentication Status:** Dynamically updates the UI based on the user's login state.
*   **Simple & Intuitive UI:** A clean interface to demonstrate the authentication flow.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   Firebase SDK (Authentication)

## Key Concepts Demonstrated
*   **OAuth:** Understanding how to use Open Authorization (OAuth) 2.0 to allow third-party applications (like this project) to access user information securely from a service provider (Google) without sharing credentials.
*   **Firebase Auth:** Practical application of Firebase Authentication as a backend service for managing user identities, handling various authentication methods, and providing secure user sessions.
*   **Popup Flow:** Implementing and managing the user experience of authenticating via a separate popup window, which is a common and secure method for OAuth flows in web applications.
*   **User Profile:** Accessing and displaying authenticated user data (such as name, email, and photo URL) provided by the identity provider (Google) after a successful login.
