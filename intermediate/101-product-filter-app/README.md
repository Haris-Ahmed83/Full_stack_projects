# Product Filter App 🛍️
> An interactive web application for dynamically filtering and searching a product catalog.

## Description
This project, "Product Filter App," is a dynamic web application designed to showcase various filtering and search functionalities. Users can efficiently browse a list of products by applying multiple criteria such as category, price range, and search terms, with the product grid updating in real-time. It provides a practical example of building responsive and user-friendly product display interfaces.

## Features
*   **Dynamic Product Filtering:** Filter products based on multiple criteria simultaneously.
*   **Real-time Search Bar:** Instantly search for products by name or description as you type.
*   **Category Tags:** Easily categorize and filter products by predefined tags.
*   **Adjustable Price Range Slider:** Refine product listings within a specific price bracket.
*   **Responsive Grid Layout:** Products are displayed in an organized and visually appealing grid that updates dynamically.
*   **Clear Filters Option:** Reset all applied filters with a single click.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS for DOM manipulation and logic)

## Key Concepts Demonstrated
*   **Filters:** Implementing multiple criteria (category, price, search) to narrow down product listings.
*   **Search Bar:** Developing live search functionality to find products by keywords.
*   **Category Tags:** Organizing and filtering products using predefined categorical labels.
*   **Price Range:** Allowing users to specify a minimum and maximum price for product selection.
*   **Grid Update:** Dynamically rendering and updating the product display based on user interactions.
