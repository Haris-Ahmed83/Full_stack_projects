# Project #87: Markdown Note Editor 📝
> A responsive web application for writing, previewing, and managing markdown notes in real-time.

## Description
The Markdown Note Editor is a user-friendly web application designed to streamline the process of creating and managing markdown content. It offers a live, side-by-side preview of your markdown as you type, ensuring a seamless writing experience. All notes are automatically saved locally, providing persistent access across sessions.

## Features
*   Real-time markdown rendering and preview in a split-pane layout.
*   Automatic saving of notes to local storage, preserving content between browser sessions.
*   Ability to export notes as markdown (`.md`) files.
*   Responsive design for a consistent experience across different devices.
*   Intuitive user interface for easy note creation and editing.
*   Supports standard markdown syntax for rich text formatting.

## Tech Stack
*   React
*   react-markdown
*   JavaScript
*   HTML
*   CSS

## Key Concepts Demonstrated
*   `react-markdown`: Efficiently parsing and rendering markdown content into HTML within a React application.
*   `Split Pane`: Implementing a resizable, two-panel layout for simultaneous editing and previewing.
*   `localStorage`: Persisting user data (notes) directly in the browser, ensuring data availability across sessions.
*   `Export`: Enabling users to download their markdown notes as `.md` files.

## Getting Started
To run this project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Haris-Ahmed83/your-project-repo-name.git
    cd your-project-repo-name
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Start the development server:**
    ```bash
    npm start
    ```
    This will open the application in your browser, usually at `http://localhost:3000`.

Alternatively, if a static build is available, you might simply open the `index.html` file in your browser to view the application.
