# Movie Search App 🎬
> Find your favorite movies and explore their details with ease.

## Description
This is an intermediate-level web application designed to allow users to search for movies using the OMDB API. It provides a clean interface to input movie titles, displays search results in an organized grid, and incorporates performance optimizations like debouncing for a smooth user experience.

## Features
*   **Real-time Movie Search**: Instantly search for movies as you type.
*   **OMDB API Integration**: Fetches comprehensive movie data from a public API.
*   **Debounced Search Input**: Optimizes API calls by delaying requests until typing pauses.
*   **Responsive Grid Display**: Presents movie results in an attractive and adaptable grid layout.
*   **User-Friendly Interface**: Simple and intuitive design for effortless navigation.
*   **Detailed Movie Information**: (Implied by OMDB API) Ability to view more details about each movie.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   OMDB API

## Key Concepts Demonstrated
*   **OMDB API**: Integration and consumption of data from an external RESTful API.
*   **Search Input**: Handling user input, event listeners, and dynamic content updates.
*   **Debouncing**: Implementing a debouncing function to optimize API calls and improve performance for frequently triggered events.
*   **Grid Display**: Utilizing CSS Grid or Flexbox for creating responsive and visually appealing layouts for search results.
