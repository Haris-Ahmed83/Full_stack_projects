# Image Gallery React 🖼️
> A dynamic and responsive image gallery built with React, showcasing modern web development concepts.

## Description
This project is an interactive image gallery application developed using React. It allows users to browse a collection of images, filter them by categories, and view them in a detailed lightbox modal. The application demonstrates modern web development practices including efficient state management, conditional rendering, and a user-friendly interface.

## Features
*   Display a curated collection of images.
*   Filter images dynamically by various categories (e.g., nature, city, animals).
*   View full-size images in an elegant, responsive lightbox modal.
*   Implement lazy loading for images to enhance performance and user experience.
*   Responsive design ensures optimal viewing across different devices and screen sizes.
*   Utilizes React Hooks for efficient state management and component lifecycle.

## Tech Stack
*   React
*   JavaScript
*   HTML
*   CSS

## Key Concepts Demonstrated
*   `useState`: Managing component state for image data, filter selections, and lightbox visibility.
*   Filtering: Implementing logic to dynamically filter and display images based on user-selected categories.
*   Lightbox: Creating an accessible and responsive modal overlay for displaying full-size images with navigation.
*   Lazy Loading: Optimizing initial load times and resource usage by loading images only as they enter the viewport.

## Getting Started
To run this project locally:
1.  Clone the repository:
    ```bash
    git clone https://github.com/Haris-Ahmed83/YOUR_REPO_NAME.git
    cd YOUR_REPO_NAME
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm start
    ```
    This will typically open the application in your browser at `http://localhost:3000`.
