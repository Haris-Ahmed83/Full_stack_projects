# Expense Tracker React 💰
> A modern web application for managing your personal finances with ease.

## Description
This project is an interactive expense tracker built with React, designed to help users monitor and categorize their spending. It provides a clear overview of financial transactions, enabling better budgeting and financial awareness through an intuitive user interface.

## Features
*   Add new income and expense transactions with descriptions and amounts.
*   View a comprehensive list of all recorded financial transactions.
*   Dynamically display the current balance based on all income and expenses.
*   Categorize transactions as either income or expense for clear differentiation.
*   Visualize expense distribution and income flow using integrated charts.
*   Delete individual transactions to maintain an accurate financial record.
*   Utilizes global state management for seamless data flow across components.

## Tech Stack
*   React
*   JavaScript (ES6+)
*   HTML5
*   CSS3

## Key Concepts Demonstrated
*   `useContext`: Utilized for efficient global state management, allowing data to be shared across the component tree without prop drilling.
*   `useReducer`: Implemented for managing complex state logic in a predictable and scalable manner, akin to Redux.
*   Global State: Centralized data management for transactions and the overall balance, ensuring all components have access to the most current financial data.
*   Chart Integration: Visual representation of financial data using a charting library to provide insightful analytics and an intuitive overview of spending habits.

## Getting Started
```bash
npm install
npm start
```
This will run the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
