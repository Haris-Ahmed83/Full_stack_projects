# Budget Planner 💰
> Your personal financial companion for smart spending and saving.

## Description
A comprehensive web application designed to help users effectively manage their finances. This tool allows you to track income and expenses, categorize transactions, and visualize your financial progress, ensuring you stay within your budget goals. It provides a clear overview of your financial health, empowering you to make informed spending decisions.

## Features
*   Add and manage income and expense transactions with ease.
*   Create and assign custom categories to your financial entries for better organization.
*   Set budget limits for different spending categories.
*   Visualize budget utilization and spending progress with intuitive progress bars.
*   View a summary of your current financial status and remaining budget.
*   Filter and sort transactions by category, type, or date.
*   Responsive design ensures a seamless experience across various devices.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   React (for Context API)

## Key Concepts Demonstrated
*   **Context API:** Utilized for efficient global state management, allowing budget data, transactions, and category information to be easily accessible across all components without prop drilling.
*   **Forms:** Implemented robust and user-friendly forms for adding new income, expenses, and managing categories, complete with input validation and submission handling.
*   **Progress Bars:** Dynamic visual indicators that represent budget utilization and spending limits for various categories, providing real-time feedback on financial progress.
*   **Categories:** A core feature enabling users to define, manage, and apply custom categories to transactions, facilitating organized tracking and detailed financial analysis.
