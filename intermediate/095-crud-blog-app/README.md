# CRUD Blog App ✍️
> A dynamic and interactive blog platform built with React and Firebase Firestore.

## Description
This project is an intermediate-level CRUD (Create, Read, Update, Delete) Blog Application designed to showcase fundamental web development concepts. Users can seamlessly create, view, edit, and delete blog posts, with all data persistently stored and managed in real-time using Firebase Firestore.

## Features
*   Create new blog posts with titles and content.
*   View a comprehensive list of all published blog posts.
*   Access detailed views for individual blog posts.
*   Edit existing blog posts, updating their titles or content.
*   Delete blog posts permanently from the database.
*   Real-time data synchronization powered by Firebase Firestore.
*   Smooth client-side navigation using React Router.

## Tech Stack
*   React
*   Firebase Firestore
*   React Router
*   JavaScript
*   HTML
*   CSS

## Key Concepts Demonstrated
*   **Firebase Firestore:** Implementing a real-time, NoSQL cloud database for persistent data storage and retrieval.
*   **React Router:** Managing client-side routing to create a multi-page application experience with dynamic URLs.
*   **CRUD Operations (Create/Edit/Delete):** Developing the core functionalities for interacting with and managing data resources.
*   **List (Data Display):** Efficiently fetching and rendering collections of data, such as a list of blog posts.

## Getting Started
To run this project locally:
1.  Navigate to the project directory.
2.  Install the necessary dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm start
    ```
    The application should open in your default browser at `http://localhost:3000`.
