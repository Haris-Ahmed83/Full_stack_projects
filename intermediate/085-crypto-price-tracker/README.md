# Crypto Price Tracker 📈
> Track cryptocurrency prices in real-time with dynamic charts.

## Description
This project is a web-based Crypto Price Tracker that allows users to monitor the real-time prices of various cryptocurrencies. It leverages external APIs to fetch up-to-the-minute data and presents it through interactive charts for a comprehensive overview.

## Features
*   Real-time cryptocurrency price tracking and updates.
*   Interactive price charts for visualizing historical data trends.
*   Dynamic updates without requiring page reloads.
*   Integration with a robust cryptocurrency data API.
*   User-friendly interface for easy monitoring of multiple coins.
*   Efficient data fetching using WebSocket technology.
*   Clear and concise display of key cryptocurrency metrics.

## Tech Stack
*   HTML
*   CSS
*   JavaScript
*   WebSocket API
*   Chart.js
*   CoinGecko API

## Key Concepts Demonstrated
*   **WebSocket API**: For establishing persistent, full-duplex communication channels, enabling real-time data streaming and updates.
*   **Chart.js**: Utilized for creating responsive and interactive charts to visualize cryptocurrency price movements over time.
*   **Real-time Updates**: Implementation of mechanisms to automatically refresh and display the latest cryptocurrency prices without user intervention.
*   **CoinGecko API**: Integration with a comprehensive third-party RESTful API to fetch a wide range of cryptocurrency market data.

- Open `index.html` in your web browser.
