# Shopping Cart Project #100 🛒
> A dynamic web application showcasing core e-commerce functionalities with React's Context API.

## Description
This project implements a fully functional shopping cart experience, allowing users to browse products, add them to a cart, manage quantities, and view a real-time total. It serves as an excellent example of state management in a modern web application, specifically utilizing React's Context API for efficient global state handling.

## Features
*   Browse a list of available products with details.
*   Add selected products to the shopping cart.
*   Increment or decrement product quantities directly within the cart.
*   Remove individual items from the cart.
*   Display a real-time subtotal and total price based on cart contents.
*   Option to clear the entire shopping cart.
*   Responsive design for a seamless experience across various devices.

## Tech Stack
*   React
*   JavaScript (ES6+)
*   HTML5
*   CSS3

## Key Concepts Demonstrated
*   **Context API**: Centralized state management for the entire shopping cart, including items, quantities, and totals, avoiding prop drilling.
*   **Add/Remove Items**: Logic for dynamically adding new products to the cart and removing existing ones.
*   **Quantity**: Implementation for managing item counts within the cart, allowing users to increase or decrease quantities.
*   **Total Calculation**: Real-time aggregation and display of the total price of all items currently in the shopping cart.

## Getting Started
To get a copy of the project up and running on your local machine for development and testing purposes, follow these steps:

1.  Clone the repository:
    ```bash
    git clone https://github.com/Haris-Ahmed83/Shopping-Cart-Project-100.git
    ```
2.  Navigate into the project directory:
    ```bash
    cd Shopping-Cart-Project-100
    ```
3.  Install the necessary dependencies:
    ```bash
    npm install
    ```
4.  Start the development server:
    ```bash
    npm start
    ```
    This will open the application in your browser, typically at `http://localhost:3000`.
