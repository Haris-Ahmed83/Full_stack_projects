# Event Scheduler 📅
> Organize your time and manage events with ease.

## Description
The Event Scheduler is a web application designed to help users efficiently manage their time and appointments. It provides a user-friendly interface for creating, viewing, updating, and deleting events, all integrated within a dynamic calendar system. This project showcases core web development principles for building interactive scheduling tools.

## Features
*   Create new events with details like title, date, and specific time slots.
*   View all scheduled events in a clear, interactive calendar format.
*   Edit existing event details, including date and time, through intuitive forms.
*   Delete events that are no longer needed, keeping your schedule up-to-date.
*   Assign events to precise time slots within a day, ensuring accurate scheduling.
*   Utilize responsive modal forms for all event creation and modification actions.
*   Seamless calendar navigation to view events across different days, weeks, or months.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **CRUD Operations**: Full functionality for creating, reading, updating, and deleting event entries, demonstrating robust data management.
*   **Calendar Integration**: Seamless display and interaction with events within a calendar-like interface, allowing users to navigate dates and view schedules.
*   **Time Slots**: Implementation of specific time slot assignments for events, ensuring precise scheduling and time management.
*   **Modal Forms**: Dynamic and user-friendly modal forms for inputting and editing event details, enhancing the user experience
