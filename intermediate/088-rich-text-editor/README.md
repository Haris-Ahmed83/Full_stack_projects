# Rich Text Editor 📝
> Empowering users with intuitive in-browser text formatting capabilities.

## Description
This project implements a web-based Rich Text Editor, providing users with a familiar interface to format text directly within their browser. It leverages modern web APIs to transform a simple `div` into a fully functional editing surface, enabling rich content creation without external libraries.

## Features
*   Apply bold, italic, and underline text styles.
*   Change font size and color.
*   Adjust text alignment (left, center, right, justify).
*   Create ordered and unordered lists.
*   Insert hyperlinks and images.
*   Undo and redo editing actions.
*   Clear all formatting with a single click.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)

## Key Concepts Demonstrated
*   `contentEditable`: Utilizing this HTML attribute to make any element editable by the user.
*   `execCommand`: Employing this JavaScript API to apply formatting commands to selected text within a `contentEditable` element.
*   Formatting: Implementing a range of text styling options, from basic bold/italic to more advanced text alignment and list creation.
*   Toolbar: Designing and integrating an interactive toolbar with buttons that trigger specific formatting actions.

## Getting Started
- Open `index.html` in your web browser.
