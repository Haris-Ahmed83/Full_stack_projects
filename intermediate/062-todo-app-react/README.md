# Todo App React 📝
> A simple and intuitive React-based Todo application for managing your daily tasks.

## Description
This project is a functional Todo application built with React, designed to help users organize and track their daily responsibilities. It provides a clean interface for managing tasks, demonstrating fundamental React concepts through a practical and interactive user experience.

## Features
*   Create new todo items.
*   Mark todo items as completed or incomplete.
*   Delete existing todo items.
*   Filter todos to view all, active, or completed tasks.
*   Clear all completed tasks with a single click.

## Tech Stack
*   React
*   JavaScript
*   HTML5
*   CSS3

## Key Concepts Demonstrated
*   **`useState`**: Utilized for managing component-level state, such as the list of todo items, input field values, and current filter selections.
*   **CRUD Operations**: Implements the core functionalities for Create (adding new todos), Read (displaying todos), Update (marking todos as complete/incomplete), and Delete (removing todos).
*   **Props**: Demonstrated through the passing of data and functions from parent components to child components (e.g., passing individual todo items to a `TodoItem` component, or handler functions for task manipulation).
*   **Lifting State Up**: The application showcases lifting state up by centralizing the main list of todo items and their manipulation logic in a common ancestor component, allowing multiple child components to access and modify the same state.

## Getting Started
- `npm install`
- `npm start` (This will typically open the app in your browser at `http://localhost:3000`)
