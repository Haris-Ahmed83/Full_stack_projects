# Sortable Table 📊
> An interactive web application showcasing dynamic table sorting capabilities.

## Description
This project implements a sortable data table, allowing users to dynamically reorder table rows based on different column values. It highlights the effective use of React's state management for UI interactivity and fundamental sorting algorithms to manage data presentation. This intermediate project is ideal for understanding how to build interactive data displays.

## Features
*   Dynamically display tabular data with multiple columns.
*   Sort data by clicking on any column header.
*   Toggle sorting direction (ascending/descending) for each column with subsequent clicks.
*   Clear visual indication of the currently sorted column and its direction.
*   Efficient data manipulation leveraging JavaScript for sorting logic.
*   Modular table component design for reusability.

## Tech Stack
*   React
*   JavaScript (ES6+)
*   HTML5
*   CSS3

## Key Concepts Demonstrated
*   **Sorting Algorithms**: Implementation of comparison-based sorting logic to reorder table data based on selected columns.
*   **useState**: Effective management of component state in React for storing table data, current sort column, and sort direction.
*   **Table Components**: Building reusable and interactive UI components for displaying structured data.
*   **Direction Toggle**: Implementing logic to switch between ascending and descending sort orders, enhancing user control over data presentation.

## Getting Started
To get a local copy up and running, follow these simple steps.
-   Clone the repository.
-   Navigate to the project directory.
-   Install dependencies: `npm install`
-   Start the development server: `npm start`
-   Open your browser and visit `http://localhost:3000` (or the address provided by `npm start`).
