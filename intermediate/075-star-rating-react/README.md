# Star Rating React ⭐
> A dynamic and accessible star rating component built with React.

## Description
This project implements an interactive star rating component using React, designed for user feedback and selection. It provides immediate visual feedback on hover and persistently displays the selected rating. A core focus of this component is ensuring a high level of accessibility for all users, including those relying on keyboard navigation and screen readers.

## Features
*   Interactive star rating selection from 1 to 5.
*   Clear visual feedback on star hover and selection.
*   Persistent display of the chosen rating.
*   Robust keyboard navigation for accessibility (arrow keys, Tab, Enter).
*   Screen reader friendly labels and ARIA attributes for enhanced usability.
*   Clean, responsive user interface.
*   Easy integration into other React applications.

## Tech Stack
*   React
*   JavaScript
*   HTML
*   CSS

## Key Concepts Demonstrated
*   **Controlled Components:** Managing the state of the star rating input directly through React state, ensuring a single source of truth for the component's value.
*   **State Management:** Effective use of `useState` hooks to manage various aspects of the component's UI, including the current rating, hover state, and selected rating.
*   **Hover States:** Implementing dynamic visual changes when a user hovers over the stars, providing intuitive feedback before a selection is made, achieved through CSS and event handlers.
*   **Accessibility:** Integrating ARIA attributes, semantic HTML, and keyboard event handlers to ensure the component is fully navigable and understandable by users with disabilities, including those using screen readers.
