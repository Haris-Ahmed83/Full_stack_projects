# Comment System 💬
> A dynamic, real-time comment and reply system powered by Firestore.

## Description
This project implements a fully functional, real-time comment system that allows users to engage in discussions. It enables seamless posting of comments, replying to existing entries, and managing content with immediate updates. The system leverages Google Firestore for robust data persistence and real-time synchronization across all clients.

## Features
*   Real-time display and updates for comments and replies.
*   Complete Create, Read, Update, and Delete (CRUD) functionality for all entries.
*   Support for nested replies, enabling multi-level conversational threads.
*   Automatic timestamping for all comments and replies upon creation.
*   Intuitive user interface for submitting new comments and interacting with existing ones.
*   Persistent storage of all comment data using Google Firestore.
*   Efficient handling of data to ensure a smooth user experience.

## Tech Stack
*   HTML
*   CSS
*   JavaScript
*   Google Firestore

## Key Concepts Demonstrated
*   **Firestore Real-time:** Implementing live data synchronization and updates across multiple clients, showcasing Firestore's real-time capabilities.
*   **CRUD Operations:** Demonstrating the fundamental Create, Read, Update, and Delete functionalities for managing comment and reply data.
*   **Nested Replies:** Structuring data models and designing the user interface to support hierarchical, multi-level comment threads.
*   **Timestamps:** Automatically generating and displaying creation timestamps for each comment and reply, providing context and order.
