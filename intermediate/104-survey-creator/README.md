# Survey Creator 📝
> Empowering users to design and preview custom surveys with ease.

## Description
This project is an interactive web application that allows users to create custom surveys. It provides an intuitive interface for adding various question types, managing their content, and instantly previewing the survey's appearance. The aim is to demonstrate core front-end development concepts like dynamic UI generation, form handling, and client-side state management.

## Features
*   Create new surveys with a user-friendly interface.
*   Add multiple question types, including text input and multiple-choice.
*   Define and manage options for multiple-choice questions.
*   Reorder or delete existing questions within the survey.
*   Real-time preview of the survey as it's being constructed.
*   Client-side management of survey structure and data.
*   Clear and responsive design for an optimal user experience.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Question Types:** Implementation of diverse input fields (e.g., text, radio buttons) to accommodate different data collection needs within a survey.
*   **Multiple Choice:** Dynamic generation and management of selectable options for questions, including adding, editing, and removing choices.
*   **State Management:** Efficient handling and updating of the survey's structure and content in the browser's memory, ensuring UI consistency and responsiveness.
*   **Results Preview:** Real-time rendering of the survey as it would appear to respondents, allowing creators to visualize and refine their design.
