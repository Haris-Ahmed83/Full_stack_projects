# Real-Time Whiteboard ✍️
> Collaborative drawing in real-time with an interactive digital canvas.

## Description
This project delivers a real-time collaborative whiteboard application, enabling multiple users to draw and interact on a shared digital canvas simultaneously. Leveraging modern web technologies, it provides an intuitive platform for brainstorming, sketching, and visual communication.

## Features
*   **Real-time Synchronization**: Instantaneous updates of drawings across all connected users.
*   **Interactive Drawing Tools**: Selectable tools like pen, eraser, and potentially others for diverse drawing needs.
*   **Multi-user Collaboration**: Seamlessly work together with others on the same canvas.
*   **Undo/Redo Functionality**: Ability to revert or reapply drawing actions for a flexible user experience.
*   **Dynamic Canvas**: A responsive drawing area powered by the HTML Canvas API.
*   **Clean User Interface**: An intuitive and minimalist design focused on drawing.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript
*   Node.js
*   Express.js
*   Socket.io

## Key Concepts Demonstrated
*   **Socket.io**: Implementation of real-time, bidirectional, event-based communication for instant drawing updates and synchronization across clients.
*   **Canvas API**: Extensive use of the HTML5 Canvas for programmatic drawing, rendering, and manipulation of graphics on the web page.
*   **Drawing Tools**: Development of interactive tools (e.g., pen, eraser) by capturing mouse/touch events and translating them into Canvas API commands.
*   **Collaboration**: Orchestration of shared state and user actions across multiple clients to facilitate a synchronous drawing experience.
*   **Undo/Redo**: Management of a history stack of drawing operations, allowing users to revert to previous states or reapply undone actions.

## Getting Started
To run this project locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/Haris-Ahmed83/Real-Time-Whiteboard.git
    ```
2.  Navigate into the project directory:
    ```bash
    cd Real-Time-Whiteboard
    ```
3.  Install the necessary Node.js dependencies:
    ```bash
    npm install
    ```
4.  Start the server:
    ```bash
    npm start
    ```
5.  Open your web browser and navigate to `http://localhost:3000` (or the port specified in your server console).
