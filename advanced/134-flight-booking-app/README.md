# Flight Booking App ✈️
> Your ultimate portal for seamless flight search, comparison, and booking.

## Description
This advanced web application provides a comprehensive platform for users to search, compare, and book flights effortlessly. It aims to deliver a user-friendly experience with robust functionalities, making travel planning straightforward and efficient from start to finish.

## Features
*   **Intuitive Flight Search**: Easily search for flights based on origin, destination, departure/return dates, and number of passengers.
*   **Advanced Filtering Options**: Refine search results by airline, price range, number of layovers, departure/arrival times, and more.
*   **Real-time Price Comparison**: View and compare prices across multiple airlines and booking options to find the best available deals.
*   **Interactive Seat Selection**: Visually select preferred seats from an aircraft layout during the booking process.
*   **Secure Booking Flow**: A guided, multi-step process for entering passenger details, making secure payments, and receiving instant confirmation.
*   **User Authentication**: Secure user accounts for managing past bookings, saving preferences, and a personalized experience.
*   **Responsive Design**: Optimized for a seamless user experience across various devices, from desktops to mobile phones.

## Tech Stack
*   **Frontend**: React.js, Redux, Tailwind CSS
*   **Backend**: Node.js, Express.js
*   **Database**: MongoDB
*   **Authentication**: JWT (JSON Web Tokens)

## Key Concepts Demonstrated
*   **Search**: Implementation of a robust search engine to query and display flight options based on various user-defined criteria.
*   **Filters**: Dynamic application of multiple filters to refine large datasets of flight results, enhancing user navigation and choice.
*   **Price Comparison**: Aggregation and clear presentation of pricing data from diverse sources to empower users in making cost-effective decisions.
*   **Seat Selection**: Development of an interactive graphical user interface allowing users to visually choose and reserve specific seats on an aircraft.
*   **Booking Flow**: Orchestration of a secure, multi-stage transaction process, guiding users from flight selection through payment and final confirmation.

## Getting Started
To get a copy of the project up and running on your local machine for development and testing purposes, follow these steps:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Haris-Ahmed83/Flight-Booking-App.git
    cd Flight-Booking-App
    ```

2.  **Install Frontend Dependencies & Start**:
    Navigate into the `client` directory, install the necessary packages, and start the React development server.
    ```bash
    cd client
    npm install
    npm start
    ```
    The frontend application will typically run on `http://localhost:3000`.

3.  **Install Backend Dependencies & Start**:
    In a new terminal window, navigate into the `server` directory, install the necessary packages, and start the Node.js backend server.
    ```bash
    cd ../server
    npm install
    npm start
    ```
    The backend API will typically run on `http://localhost:5000`.

*Note: Ensure you have Node.js and npm installed on your system.*
