# Music Streamer 🎶
> Your personal hub for endless audio enjoyment.

## Description
Music Streamer is an advanced web application designed to provide a rich and interactive music listening experience. It allows users to explore a vast library of tracks, create personalized playlists, and manage their listening queue seamlessly. Built with modern web technologies, this project showcases robust front-end development and dynamic content management.

## Features
*   **Dynamic Music Playback:** Seamlessly play, pause, skip, and scrub through tracks.
*   **Curated Playlists:** Create, save, and manage custom playlists for different moods and occasions.
*   **Powerful Search Functionality:** Easily find your favorite songs, artists, and albums within the music library.
*   **Intuitive Player Controls:** Comprehensive controls including volume adjustment, repeat modes, and shuffle functionality.
*   **Real-time Queue Management:** Add, reorder, and remove songs from your dynamic listening queue.
*   **Responsive UI:** Enjoy a consistent and optimized user experience across various devices.
*   **Web Audio API Integration:** Leverages the Web Audio API for high-quality audio processing and custom playback features.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   Web Audio API

## Key Concepts Demonstrated
*   **Audio API:** Direct manipulation and control of audio playback using the browser's Web Audio API for an enhanced listening experience.
*   **Playlists:** Implementation of CRUD (Create, Read, Update, Delete) operations for user-generated song collections, allowing for personalized music organization.
*   **Search:** Efficient filtering and retrieval of music tracks, artists, and albums from a dataset, providing quick access to desired content.
*   **Player Controls:** Development of a comprehensive user interface for managing audio playback states, including play/pause, volume, seek, repeat, and shuffle functionalities.
*   **Queue Management:** Dynamic handling of the upcoming song list, enabling users to add, reorder, and remove tracks to customize their listening flow.

## Getting Started
- Open `index.html` in your browser (or `npm install && npm start` for React/Node based projects)
