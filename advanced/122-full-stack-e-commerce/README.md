# Full Stack E-Commerce Platform 🛍️
> A comprehensive online shopping experience built with the MERN stack.

## Description
This project is a robust, full-stack e-commerce application designed to provide a complete online shopping experience. It encompasses user authentication, product management, a dynamic shopping cart, secure payment processing, and an administrative dashboard for efficient store management.

## Features
*   User authentication (registration, login, logout)
*   Browse products with detailed product pages
*   Dynamic shopping cart functionality (add, remove, update quantities)
*   Secure checkout process with Stripe integration
*   User order history and tracking
*   Admin panel for product, user, and order management
*   Responsive design for various devices

## Tech Stack
*   MongoDB
*   Express.js
*   React.js
*   Node.js
*   Stripe API
*   JSON Web Tokens (JWT) for authentication

## Key Concepts Demonstrated
*   **MERN Stack:** Full-stack development leveraging MongoDB, Express.js, React.js, and Node.js for a cohesive and scalable web application.
*   **Stripe Payments:** Integration of the Stripe API for secure and efficient payment processing, handling credit card transactions.
*   **Cart:** Implementation of a dynamic shopping cart system, allowing users to add, remove, and update product quantities before proceeding to checkout.
*   **Orders:** Management and tracking of user orders, including order creation, history display, and status updates.
*   **Admin Panel:** Development of a restricted administrative interface for managing products, users, and orders, ensuring comprehensive operational control.

## Getting Started
To run this project locally:
```bash
# Clone the repository
git clone <repository-url>

# Install dependencies for both client and server
cd client && npm install
cd ../server && npm install

# Start the client and server (usually concurrent scripts or separate commands)
# Example:
# In client directory: npm start
# In server directory: npm start
```
Alternatively, for a general MERN setup:
- `npm install` in both client and server directories
- `npm start` in both client and server directories (often using `concurrently` or separate terminal tabs)
