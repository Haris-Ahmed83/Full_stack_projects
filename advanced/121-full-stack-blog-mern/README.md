# Full Stack Blog MERN 📝
> A robust, full-stack blogging platform built with the MERN stack.

## Description
This project is a comprehensive full-stack blogging application designed to showcase the power of the MERN stack. It enables users to create, read, update, and delete their blog posts, featuring secure user authentication and rich content creation through Markdown.

## Features
*   User authentication (signup, login, logout)
*   Create, view, edit, and delete blog posts (full CRUD functionality)
*   Rich text post creation using Markdown syntax
*   Display a list of all available blog posts
*   View individual blog posts with their full content
*   Protected routes ensuring only authenticated users can manage posts
*   Responsive design for various screen sizes

## Tech Stack
*   MongoDB
*   Express.js
*   React.js
*   Node.js
