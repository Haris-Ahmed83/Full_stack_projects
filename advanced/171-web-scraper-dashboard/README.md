# Web Scraper Dashboard 📊
> A comprehensive dashboard for visualizing and managing web scraped data.

## Description
This project delivers a robust web-based dashboard designed to perform, visualize, and manage data extracted from various websites. It leverages powerful scraping tools to gather information and presents it through an intuitive, user-friendly interface for easy analysis and interaction.

## Features
*   Execute targeted web scraping tasks with configurable parameters.
*   Display scraped data visually using interactive tables and charts.
*   Schedule automated scraping jobs for continuous data collection.
*   Export collected data to CSV format for external analysis and reporting.
*   Review and manage historical scraping runs and their associated outputs.
*   Provides a clean and responsive user interface for seamless navigation.

## Tech Stack
*   Node.js
*   Puppeteer
*   Cheerio
*   HTML
*   CSS
*   JavaScript

## Key Concepts Demonstrated
*   **Puppeteer**: Utilized for advanced web scraping, enabling interaction with dynamic content, handling browser automation, and extracting data from JavaScript-rendered pages.
*   **Cheerio**: Employed for efficient and lightweight parsing of HTML content, facilitating quick and jQuery-like selection and extraction of structured data.
*   **Data Display**: Implemented through a dashboard interface to present scraped information visually using tables, charts, and interactive elements for enhanced understanding.
*   **Scheduling**: Functionality to automate web scraping jobs at predefined intervals, ensuring regular and up-to-date data collection without manual intervention.
*   **Export CSV**: Provides the capability to download extracted data in CSV format, allowing for easy integration with spreadsheets or other data analysis tools.
