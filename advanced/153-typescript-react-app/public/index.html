Project #153: TypeScript React App

Category: advanced

This project demonstrates a robust React application built with TypeScript, emphasizing strong typing, code organization, and advanced TypeScript features for enhanced developer experience and maintainability.

Key Concepts Demonstrated:

  • TypeScript: Core language features for type declaration, inference, and compilation.
  • Interfaces: Defining custom types for props, state, and data structures to ensure type consistency across components and services.
  • Generics: Creating reusable components and functions that can work with a variety of types while maintaining type safety.
  • Type Safety: Leveraging TypeScript's compiler to catch common errors at compile-time rather than runtime, leading to more reliable applications.
  • React Hooks: Utilizing useState, useEffect, useContext, useReducer, and custom hooks with TypeScript types.

Project Structure & Setup:

A typical setup would involve creating a React app with TypeScript:

npx create-react-app my-ts-react-app --template typescript cd my-ts-react-app npm start

This project will focus on the src directory content, specifically how components, hooks, and data structures are defined using TypeScript.

Example: Typed Component with Props and State

Consider a simple counter component:

src/components/Counter.tsx

import React, { useState } from 'react'; // 1. Define an Interface for Component Props interface CounterProps { initialCount?: number; label: string; } const Counter: React.FC<CounterProps> = ({ initialCount = 0, label }) => { // 2. Use useState with Type Annotation const [count, setCount] = useState<number>(initialCount); const increment = () => { setCount(prevCount => prevCount + 1); }; const decrement = () => { setCount(prevCount => prevCount - 1); }; return ( <div style={{ border: '1px solid #ccc', padding: '15px', borderRadius: '5px', marginBottom: '10px' }}> <h3>{label}</h3> <p>Count: <strong>{count}</strong></p> <button onClick={increment} style={{ marginRight: '5px' }}>Increment</button> <button onClick={decrement}>Decrement</button> </div> ); }; export default Counter;

Example: Using Generics for Reusable Components

A generic list component that can display items of any type:

src/components/GenericList.tsx

import React from 'react'; // 1. Define an Interface for a generic item with an 'id' property interface HasId { id: string | number; } // 2. Define a Generic Component // <T extends HasId> ensures that the items passed to this component // will always have an 'id' property, allowing safe key access. interface GenericListProps<T extends HasId> { items: T[]; renderItem: (item: T) => React.ReactNode; // Function to render each item } // Use React.FC with generics for better type inference for children (if any) function GenericList<T extends HasId>({ items, renderItem }: GenericListProps<T>) { return ( <ul style={{ listStyleType: 'none', padding: 0 }}> {items.map(item => ( <li key={item.id} style={{ marginBottom: '8px', padding: '8px', border: '1px solid #eee', borderRadius: '4px' }}> {renderItem(item)} </li> ))} </ul> ); } export default GenericList;

Example: App Integration

src/App.tsx

import React from 'react'; import Counter from './components/Counter'; import GenericList from './components/GenericList'; // Define interfaces for different data types interface User { id: number; name: string; email: string; } interface Product { id: string; productName: string; price: number; } const App: React.FC = () => { const users: User[] = [ { id: 1, name: 'Alice', email: 'alice@example.com' }, { id: 2, name: 'Bob', email: 'bob@example.com' }, ]; const products: Product[] = [ { id: 'p1', productName: 'Laptop', price: 1200 }, { id: 'p2', productName: 'Mouse', price: 25 }, ]; return ( <div style={{ padding: '20px' }}> <h1>TypeScript React App Demo</h1> <h2>Counters with Typed Props</h2> <Counter label="Simple Counter" /> <Counter initialCount={5} label="Advanced Counter" /> <h2>Generic List of Users</h2> <GenericList items={users} renderItem={(user) => ( <div> <strong>{user.name}</strong> ({user.email}) </div> )} /> <h2>Generic List of Products</h2> <GenericList items={products} renderItem={(product) => ( <div> <strong>{product.productName}</strong> - ${product.price.toFixed(2)} </div> )} /> </div> ); }; export default App;
