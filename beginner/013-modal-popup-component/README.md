# Modal Popup Component 🖼️
> A simple, responsive, and reusable modal window built with vanilla JavaScript, HTML, and CSS.

## Description
This project implements a classic modal popup window, a common UI element used to display content on top of the main application. It showcases fundamental front-end techniques for creating interactive and accessible overlay components, perfect for displaying alerts, forms, or additional information.

## Features
*   Click a button to open the modal.
*   Close the modal by clicking a designated close button.
*   Close the modal by pressing the `Escape` key.
*   Close the modal by clicking on the overlay outside the modal content.
*   Smooth transition effects for opening and closing the modal.
*   Dimmable background overlay to focus user attention on the modal.
*   Modular and reusable component structure using vanilla JavaScript.

## Tech Stack
*   HTML
*   CSS
*   JavaScript

## Key Concepts Demonstrated
*   **CSS Positioning:** Utilized for precisely placing the modal in the center of the viewport and managing its relationship with other page elements.
*   **Z-index:** Ensures the modal and its overlay appear on top of all other content, preventing interference with the main page.
*   **Transitions:** Implemented for a smooth and visually appealing animation when the modal opens and closes.
*   **Event Bubbling:** Employed to efficiently detect clicks outside the modal content (e.g., on the overlay) to trigger its closure.
