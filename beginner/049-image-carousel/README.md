# Image Carousel 🎠
> A dynamic and interactive image display built with core web technologies.

## Description
This project implements a classic image carousel, showcasing a collection of images with smooth transitions. It demonstrates fundamental web development concepts to create an engaging user experience for browsing visual content.

## Features
*   Displays a sequence of images in a compact, scrollable container.
*   Automatic image progression at a set interval.
*   Manual navigation through images using "Previous" and "Next" buttons.
*   Smooth visual transitions between images for an enhanced user experience.
*   Responsive design, adapting to various screen sizes.
*   Clear indication of the currently active image.
*   Built purely with HTML, CSS, and vanilla JavaScript.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **CSS Transforms**: Utilized for positioning and animating image elements efficiently.
*   **Transitions**: Implemented to create smooth, visually appealing changes when images slide or fade.
*   **setInterval**: Used to automate the image progression, allowing the carousel to advance automatically.
*   **Button Controls**: Demonstrates event handling and DOM manipulation for user-driven navigation.

## Getting Started
- Open `index.html` in your web browser.
