# Memory Card Game 🃏
> Test your memory and concentration with this classic card-matching game.

## Description
This project implements a classic memory card game, challenging players to find matching pairs of cards. Built with fundamental web technologies, it offers an interactive and engaging experience while demonstrating core game development principles.

## Features
*   Interactive card-flipping mechanism.
*   Timer to track game duration.
*   Move counter to track player attempts.
*   Responsive design for various screen sizes.
*   Visual feedback for correct and incorrect matches.
*   Game reset functionality to play again.
*   Engaging 3D card flip animations.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Array Shuffling:** Implementation of algorithms to randomize card positions, ensuring a unique game setup each time.
*   **Game Logic:** Management of game state, handling card clicks, checking for matches, and determining game completion.
*   **`setTimeout`:** Utilization of asynchronous JavaScript for controlled delays, such as briefly showing unmatched cards before flipping them back.
*   **CSS 3D Transforms:** Creation of realistic and engaging card flip animations using properties like `transform: rotateY()`, `perspective`, and `transform-style: preserve-3d`.

## Getting Started
To get started with this project, simply:
- Open `index.html` in your web browser.
