# Interactive Quiz App 🧠
> A fun and engaging way to test your knowledge with a dynamic quiz experience.

## Description
This project is an interactive web-based quiz application designed to challenge users with multiple-choice questions. It provides instant feedback, tracks scores, and offers a user-friendly interface for an engaging learning experience, perfect for demonstrating fundamental web development concepts.

## Features
*   Presents multiple-choice questions one at a time.
*   Provides instant feedback on selected answers (correct/incorrect).
*   Tracks and displays the user's score upon quiz completion.
*   Offers a clear option to restart the quiz and play again.
*   Dynamically loads and renders questions and options.
*   Simple and intuitive user interface.
*   Handles end-of-quiz state with final score display.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)

## Key Concepts Demonstrated
*   **DOM Manipulation:** Dynamically updating quiz questions, answer options, and results on the web page.
*   **Event Listeners:** Handling user interactions such as selecting an answer, submitting, and restarting the quiz.
*   **Arrays:** Storing quiz questions, answer options, and managing question order.
*   **Score Tracking:** Implementing logic to keep count of correct answers and display the final score.

## Getting Started
To run this project locally, simply open the `index.html` file in your preferred web browser.
