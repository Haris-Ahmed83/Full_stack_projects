# Drum Kit App 🥁
> Play a virtual drum kit right in your browser using your keyboard!

## Description
This interactive web application transforms your keyboard into a fun and responsive drum kit. Users can trigger various drum sounds by pressing corresponding keys, providing an engaging way to learn about web development fundamentals. It's a perfect beginner project to explore key web APIs and front-end interactivity.

## Features
*   Play distinct drum sounds using specific keyboard keys (e.g., A, S, D, F, G, H, J, K, L).
*   Visual feedback (CSS animations) on drum pads when a key is pressed.
*   Clear and intuitive user interface for an enjoyable experience.
*   Responsive design ensures functionality across different screen sizes.
*   Seamless audio playback for each drum sound.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Key Events:** Capturing keyboard presses (`keydown`, `keyup`) to trigger specific actions and play sounds.
*   **Web Audio API:** Programmatically playing audio files in response to user input, providing an immersive sound experience.
*   **CSS Animations:** Applying dynamic visual effects (like scaling, glowing, or transitions) to elements to provide immediate feedback when a drum is hit.
*   **Event Listeners:** Attaching functions to DOM elements or the `window` object to react to user interactions (e.g., `addEventListener`).

## Getting Started
To run this project locally:
- Open `index.html` directly in your web browser.
