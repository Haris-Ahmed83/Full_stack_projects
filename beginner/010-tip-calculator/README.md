# Tip Calculator 💰
> Easily calculate tips and split bills with a user-friendly interface.

## Description
This project is a simple yet effective web-based tip calculator designed to help users quickly determine tip amounts and split bills among multiple people. It provides a straightforward way to input the total bill, select a tip percentage, and see the breakdown of the tip, total bill, and individual contributions.

## Features
*   Input field for the total bill amount.
*   Pre-defined tip percentage options (e.g., 10%, 15%, 20%).
*   Option to input a custom tip percentage.
*   Slider to specify the number of people sharing the bill.
*   Real-time calculation and display of the tip amount.
*   Real-time calculation and display of the total bill (with tip).
*   Real-time calculation and display of the amount each person needs to pay.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Input Handling:** Capturing and processing user input from text fields, selection options, and sliders.
*   **Math Operations:** Performing fundamental arithmetic operations (addition, multiplication, division) for calculations.
*   **Percentage Calculations:** Implementing logic to correctly calculate a percentage of a given numerical value.
*   **Sliders:** Utilizing HTML range input elements to provide an interactive way to select a numerical value.
