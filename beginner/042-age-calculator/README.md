# Age Calculator 📅
> A simple web application to calculate age based on a birthdate.

## Description
This project is a beginner-friendly web application designed to calculate a person's current age based on their birthdate. Users can input their date of birth, and the application will dynamically display their age in years, months, and days. It serves as an excellent introduction to fundamental web development concepts.

## Features
*   Accepts user input for birthdate via a date picker.
*   Calculates age accurately in years, months, and days.
*   Correctly handles calculations involving leap years.
*   Provides dynamic, real-time age calculation results.
*   User-friendly interface for easy date selection and result viewing.
*   Clearly displays the calculated age.

## Tech Stack
*   HTML
*   CSS
*   JavaScript

## Key Concepts Demonstrated
*   **Date Manipulation:** Working with `Date` objects, calculating time differences, and formatting date outputs.
*   **Input Types:** Utilizing `<input type="date">` for user-friendly and standardized date selection.
*   **Leap Years:** Implementing logic to correctly account for leap years in age calculations to ensure accuracy.
*   **Dynamic Results:** Updating the user interface instantly based on user input without requiring a page reload.
