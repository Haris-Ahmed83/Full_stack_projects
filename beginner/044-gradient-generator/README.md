# Gradient Generator ✨
> Craft and explore beautiful CSS gradients with ease.

## Description
This project is a simple web application designed to help users create and visualize CSS linear gradients. It provides interactive controls to customize gradient properties, dynamically generate the corresponding CSS code, and offers a real-time preview of the gradient.

## Features
*   Generate linear CSS gradients interactively.
*   Adjust gradient direction using a range input.
*   Select multiple colors for the gradient.
*   Add or remove color stops dynamically.
*   Randomly generate unique gradient combinations.
*   Copy generated CSS code to the clipboard with a single click.
*   Real-time visual preview of the gradient.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **CSS Gradients:** Dynamic generation and application of linear gradients using CSS properties for visual styling.
*   **Input Ranges:** Utilizing `<input type="range">` elements for interactive control over numerical values, such as gradient direction.
*   **Random Generation:** Implementing JavaScript logic to produce random color values and gradient configurations for creative exploration.
*   **Clipboard Copy:** Programmatically copying generated CSS code to the user's clipboard using JavaScript's Clipboard API.

## Getting Started
- Open `index.html` in your browser.
