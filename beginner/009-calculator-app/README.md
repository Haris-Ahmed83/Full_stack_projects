# Calculator App 🧮
> A sleek and functional web-based calculator for everyday arithmetic.

## Description
This project is a simple yet fully functional web calculator designed to perform basic arithmetic operations. Built with a focus on a clean user interface and robust functionality, it provides a practical example of front-end web development principles. It serves as an excellent starting point for understanding interactive web applications.

## Features
*   Perform basic arithmetic operations: addition, subtraction, multiplication, and division.
*   Clear all input with a dedicated 'AC' button.
*   Handle decimal numbers for precise calculations.
*   Display real-time calculation results.
*   Responsive design ensuring usability across different screen sizes.
*   Intuitive user interface for easy interaction.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Event Delegation:** Efficiently managing events for multiple calculator buttons using a single event listener on a parent element.
*   **`eval()` Function:** Utilizing JavaScript's `eval()` function for dynamic expression evaluation.
*   **Switch Statements:** Implementing control flow for different operator actions.
*   **CSS Grid Layout:** Structuring the calculator's keypad and display for a clean and responsive layout.

## Getting Started
- Open `index.html` in your preferred web browser.
