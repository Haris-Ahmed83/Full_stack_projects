# Character Counter 📝
> A simple web tool to count characters and words in real-time.

## Description
This project provides a straightforward web application to count characters as you type. It offers instant feedback on input length, helping users stay within specified limits for text fields.

## Features
*   Real-time character counting as text is entered.
*   Displays the current character count dynamically.
*   Supports setting and enforcing character limits for input fields.
*   Provides visual feedback (e.g., color change) when approaching or exceeding limits.
*   User-friendly and intuitive interface.
*   Responsive design for various screen sizes.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Input Events:** Capturing and responding to user input in text areas.
*   **String Length:** Calculating the length of user-entered strings.
*   **Real-time Count:** Updating displayed counts dynamically as the user types.
*   **Limits:** Implementing and enforcing character constraints on input fields.

## Getting Started
*   Open `index.html` in your browser.
