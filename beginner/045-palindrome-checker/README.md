# Palindrome Checker 🔄
> Instantly verify if a word or phrase reads the same forwards and backwards.

## Description
This project is a simple web application designed to check if a given input string is a palindrome. It provides immediate feedback, making it easy to understand the concept of palindromes and how they are identified programmatically. This beginner-friendly project highlights fundamental JavaScript string manipulation techniques.

## Features
*   Checks if a given word or phrase is a palindrome.
*   Provides instant feedback on the input status.
*   Handles various types of input, including sentences and special characters.
*   Ignores capitalization and non-alphanumeric characters for accurate checks.
*   Clear and user-friendly interface.
*   Built with a focus on fundamental web development concepts.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **String Methods:** Utilizing methods like `toLowerCase()`, `replace()`, `split()`, and `join()` for string manipulation and normalization.
*   **Array Reverse:** Employing array methods (e.g., `split('').reverse().join('')`) to reverse the processed string for comparison.
*   **Case Insensitive:** Implementing logic to ignore letter casing, ensuring "Racecar" and "racecar" are both recognized as palindromes.
*   **RegEx (Regular Expressions):** Using regular expressions to filter out non-alphanumeric characters (spaces, punctuation, symbols) from the input string before checking for palindrome status.
