# Random Quote Generator 💬
> Inspire yourself with a new quote at the click of a button.

## Description
This is a beginner-friendly web application designed to generate and display random quotes. It provides a simple and engaging way for users to discover new inspirational or thought-provoking quotes with minimal interaction. The project focuses on fundamental web development concepts, making it an excellent starting point for learning client-side programming.

## Features
*   Displays a random quote and its author upon initial page load.
*   Allows users to generate a new random quote by clicking a dedicated button.
*   Dynamically updates the quote and author on the page without requiring a full page reload.
*   Utilizes a collection of pre-defined quotes for variety.
*   Provides a clean and straightforward user interface.
*   Built entirely with client-side technologies.

## Tech Stack
*   HTML
*   CSS
*   JavaScript

## Key Concepts Demonstrated
*   **Arrays:** Used to store a collection of quotes and their respective authors.
*   **Math.random:** Implemented to select a random index from the array, enabling the display of a different quote each time.
*   **DOM Manipulation:** Demonstrates how to select and update elements on the web page (e.g., changing the text content of the quote and author display areas).
*   **Event Listeners:** Utilized to detect user interaction, specifically a button click, to trigger the generation of a new quote.

## Getting Started
- Open `index.html` in your web browser.
