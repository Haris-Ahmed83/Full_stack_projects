# Digital Clock ⏰
> A simple, real-time digital clock built with vanilla JavaScript.

## Description
This project is a beginner-friendly web application that displays the current time in a digital format. It serves as an excellent introduction to handling time-based events and dynamic UI updates using fundamental web technologies.

## Features
*   Displays current time (hours, minutes, seconds).
*   Updates in real-time without page refresh.
*   Clean and minimalist user interface.
*   Utilizes the browser's native Date object for accurate time.
*   Formats time to ensure consistent two-digit display.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Date Object:** Used to retrieve the current date and time information, including hours, minutes, and seconds.
*   **setInterval:** Employed to repeatedly call a function every second, ensuring the clock updates in real-time.
*   **Template Literals:** Utilized for easily formatting and inserting dynamic time values into the HTML structure.
*   **Time Formatting:** Implemented logic to ensure consistent two-digit display for hours, minutes, and seconds (e.g., `05` instead of `5`).

## Getting Started
- Open `index.html` in your web browser.
