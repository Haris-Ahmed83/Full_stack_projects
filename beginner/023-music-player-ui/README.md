# Music Player UI 🎵
> A sleek and interactive web-based music player interface built with fundamental front-end technologies.

## Description
This project delivers a functional and visually appealing music player user interface. It allows users to play, pause, seek through, and control the volume of audio tracks directly within their browser. Designed as a beginner-friendly project, it effectively demonstrates core web development concepts.

## Features
*   **Play/Pause Functionality:** Seamlessly start and stop audio playback.
*   **Seek Bar:** Drag-and-drop slider to navigate through the audio track.
*   **Volume Control:** Adjust the playback volume with a dedicated slider.
*   **Time Display:** Shows current playback time and total track duration.
*   **Dynamic UI Updates:** Play/pause button icon changes based on player state.
*   **Responsive Design:** Adapts to various screen sizes for a consistent user experience.
*   **Smooth Animations:** Subtle CSS animations provide visual feedback for interactions.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla)

## Key Concepts Demonstrated
*   **HTML Audio API:** Utilized for programmatically controlling audio playback, including `play()`, `pause()`, `currentTime`, `duration`, and `volume`.
*   **Event Listeners:** Implemented to respond to user interactions (e.g., button clicks, slider input changes) and audio events (e.g., `timeupdate`, `ended`).
*   **Range Sliders:** Employed for creating interactive seek bars for audio progress and volume control, allowing users to intuitively adjust settings.
*   **CSS Animations:** Applied to enhance the user experience with smooth transitions and visual feedback for elements like buttons and progress indicators.
