# BMI Calculator 🏋️
> A simple web application to calculate your Body Mass Index and categorize your health.

## Description
This project is a straightforward BMI (Body Mass Index) Calculator designed to help users quickly assess their health status based on their weight and height. It takes user input, performs the necessary calculation, and then displays the BMI score along with a health category, providing instant feedback.

## Features
*   Input fields for weight (in kg) and height (in cm or meters).
*   Accurate BMI calculation based on standard formula.
*   Clear display of the calculated BMI score.
*   Categorization of BMI into standard health ranges (e.g., Underweight, Normal, Overweight, Obese).
*   Dynamic styling of results based on the BMI category for visual feedback.
*   Input validation to ensure valid numerical entries.
*   Reset functionality to clear inputs and results.

## Tech Stack
*   HTML
*   CSS
*   JavaScript

## Key Concepts Demonstrated
*   **Forms**: Handling user input from HTML form elements (input fields, buttons) and preventing default form submission behavior.
*   **Calculations**: Implementing the mathematical formula for BMI (weight in kg / (height in meters * height in meters)).
*   **Categories**: Defining and applying logic to classify a numerical result (BMI score) into distinct health ranges.
*   **Conditional CSS Classes**: Dynamically adding or removing CSS classes to elements based on JavaScript logic to change their appearance according to the calculated BMI category.
