# Lightbox Gallery 🖼️
> A simple and interactive image gallery with a fullscreen overlay for an enhanced viewing experience.

## Description
This project implements a classic Lightbox Gallery, allowing users to view images in an elegant fullscreen overlay. It provides an intuitive way to browse through a collection of photos without leaving the current page. Designed as a beginner-friendly project, it focuses on core front-end interactions and visual effects.

## Features
*   Clickable thumbnails to open images in a fullscreen lightbox.
*   Smooth transition animations for opening and closing the lightbox.
*   Navigation arrows (previous/next) within the lightbox to browse images.
*   Keyboard support for navigation (left/right arrow keys) and closing (Escape key).
*   Overlay background to focus user attention on the active image.
*   Responsive design for various screen sizes.
*   Ability to close the lightbox by clicking outside the image or using a dedicated close button.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Fullscreen Overlay**: Creating a modal-like component that covers the entire viewport.
*   **Image Navigation**: Implementing logic to cycle through a collection of images.
*   **Keyboard Events**: Handling user input from the keyboard for enhanced accessibility and control.
*   **Animations**: Applying CSS transitions or JavaScript animations for a smoother user experience.
