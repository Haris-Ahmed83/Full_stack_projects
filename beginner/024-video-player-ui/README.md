# Video Player UI 🎬
> A custom-built, interactive video player interface using plain HTML, CSS, and JavaScript.

## Description
This project demonstrates the creation of a modern, responsive video player from scratch. It replaces the browser's default video controls with a set of custom-designed UI elements, offering a more tailored user experience. Built with a focus on core web technologies, it's an excellent example for beginners to understand front-end interaction.

## Features
*   Custom play/pause button functionality
*   Adjustable volume control with mute toggle
*   Interactive progress bar for seeking through the video
*   Displays current playback time and total video duration
*   Fullscreen mode toggle for an immersive viewing experience
*   Clean, intuitive user interface design
*   Responsive layout for various screen sizes

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **HTML5 Video API**: Programmatically controlling video playback, duration, current time, and other media properties.
*   **Custom Controls**: Implementing bespoke play/pause, volume, and fullscreen buttons and their event listeners, replacing default browser controls.
*   **Fullscreen API**: Toggling the video element into and out of fullscreen mode for enhanced viewing.
*   **Progress Bar**: Dynamically updating a visual indicator based on video playback progress and allowing users to seek to different parts of the video.
