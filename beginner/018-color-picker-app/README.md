# Color Picker App 🎨
> A simple yet powerful tool for selecting and manipulating colors.

## Description
This Color Picker App is a beginner-friendly web project designed to demonstrate fundamental front-end development concepts. It allows users to interactively select colors, view their RGB and HEX representations, and easily copy color codes to the clipboard. Ideal for developers looking to understand input handling, color conversions, and basic DOM manipulation.

## Features
*   Interactive color selection using a native color input.
*   Real-time display of the selected color in a dedicated preview area.
*   Automatic conversion and display of the selected color in RGB format.
*   Automatic conversion and display of the selected color in HEX format.
*   One-click copying of the RGB color code to the user's clipboard.
*   One-click copying of the HEX color code to the user's clipboard.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Input Events:** Handling `change` and `input` events from color input fields to provide real-time updates.
*   **RGB/HEX Conversion:** Implementing logic to convert color values between RGB and hexadecimal formats.
*   **Color Manipulation:** Dynamically updating background colors and text content based on user selections.
*   **Clipboard API:** Utilizing the `navigator.clipboard.writeText()` method for seamless copying of color codes.
