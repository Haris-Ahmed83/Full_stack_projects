# Piano App 🎹
> A simple, interactive virtual piano built with web technologies.

## Description
The Piano App is a beginner-friendly web project that simulates a virtual piano. It allows users to play musical notes by clicking on the on-screen piano keys or by using their computer keyboard. This project serves as an excellent introduction to handling browser events and working with audio in web development.

## Features
*   Interactive virtual piano interface.
*   Play notes by clicking on the on-screen keys.
*   Play notes using the computer keyboard (mapped to specific keys).
*   Realistic piano sound for each note.
*   Visually responsive keys on interaction.
*   Simple and intuitive user experience.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Keyboard Events:** Handling user input from the computer keyboard to trigger piano notes.
*   **Audio Context:** Utilizing the Web Audio API to generate and play dynamic sound.
*   **CSS Flexbox:** Structuring and styling the piano keys for a responsive layout.
*   **Data Attributes:** Storing and accessing key-specific data directly within HTML elements.

## Getting Started
- Open `index.html` in your web browser.
