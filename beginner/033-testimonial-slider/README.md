# Testimonial Slider 💬
> A sleek and interactive testimonial carousel built with vanilla JavaScript.

## Description
This project showcases a dynamic testimonial slider, allowing users to browse through customer feedback with smooth transitions. It's a great example of implementing a classic UI component using fundamental web technologies, perfect for enhancing any website's user engagement.

## Features
*   Smooth sliding transitions between testimonials.
*   Automatic rotation of testimonials at a set interval.
*   Manual navigation using previous/next buttons.
*   Dot navigation for direct access to any testimonial.
*   Responsive design for various screen sizes.
*   Clear display of author name, photo, and testimonial text.
*   Built purely with HTML, CSS, and JavaScript.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Carousel**: Implementing a rotating display of content items.
*   **setInterval**: Using JavaScript to trigger functions repeatedly at a fixed time delay for auto-play functionality.
*   **CSS Transforms**: Applying `translate` for smooth horizontal movement of testimonial slides.
*   **Dot Navigation**: Creating interactive indicators to jump to specific slides within the carousel.
