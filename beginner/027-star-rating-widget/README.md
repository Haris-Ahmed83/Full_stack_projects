# Star Rating Widget ⭐
> An interactive star rating component built with vanilla JavaScript.

## Description
This project implements a simple yet effective star rating widget, perfect for beginner front-end developers. It showcases fundamental web development concepts by allowing users to select a rating through an intuitive visual interface. The widget is designed to be easily integrated into various web applications.

## Features
*   Interactive star selection on hover and click.
*   Visual feedback for hovered and selected ratings.
*   Persistence of the selected rating until a new one is chosen.
*   Utilizes Unicode characters for star icons.
*   Clear and responsive styling for an enhanced user experience.
*   Built entirely with vanilla JavaScript, HTML, and CSS.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)

## Key Concepts Demonstrated
*   **Event Handling**: Capturing user interactions such as `mouseover`, `mouseout`, and `click` events to update the widget's state and appearance.
*   **CSS Classes**: Dynamically adding and removing CSS classes to apply different styles based on the widget's state (e.g., active star, hovered star).
*   **Unicode Characters**: Using Unicode star characters (`⭐`, `☆`) as visual elements for the rating system, avoiding image assets.
*   **State Management**: Maintaining and updating the current rating selection within the JavaScript logic, reflecting it accurately in the UI.
