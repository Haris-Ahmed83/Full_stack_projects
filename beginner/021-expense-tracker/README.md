# Expense Tracker 💰
> A simple web application to manage your daily expenses and visualize spending habits.

## Description
This project is a beginner-friendly web application designed to help users track their income and expenses. It demonstrates fundamental web development concepts by allowing users to add, view, edit, and delete transactions, providing a clear overview of their financial activities.

## Features
*   Add new income or expense transactions with descriptions and amounts.
*   View a comprehensive list of all recorded transactions.
*   Edit existing transaction details for accuracy.
*   Delete unwanted transactions from the list.
*   Display a real-time current balance (total income minus total expenses).
*   Visualize expense distribution or trends using an interactive chart.
*   Persist all transaction data locally in the browser for future sessions.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **CRUD Operations:** Implementing Create, Read, Update, and Delete functionalities for expense records.
*   **localStorage:** Persisting user data directly in the browser, ensuring data is not lost on page refresh.
*   **Chart Display:** Integrating a charting solution to visualize financial data and spending patterns effectively.
*   **Form Handling:** Managing user input through forms to add and modify transaction details.

## Getting Started
- Open `index.html` in your web browser.
