# Word Counter App 📝
> Instantly analyze text with real-time word, character, and sentence counts.

## Description
This project is a simple yet powerful web-based word counter application. It allows users to paste or type text into a textarea and receive immediate statistics about their input, such as word count, character count, and more. Designed for beginners, it showcases fundamental web development concepts.

## Features
*   Real-time word counting as you type.
*   Character count (including and excluding spaces).
*   Sentence count.
*   Paragraph count.
*   Estimated reading time.
*   Clean and responsive user interface.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)

## Key Concepts Demonstrated
*   **Text Analysis:** Processing raw text input to extract meaningful statistics like word, character, sentence, and paragraph counts.
*   **RegEx (Regular Expressions):** Utilizing regular expressions for advanced pattern matching, such as accurately identifying words, sentences, or paragraphs within the input text.
*   **Real-time Updates:** Implementing immediate feedback to the user as they type, updating all displayed counts dynamically without requiring a page refresh.
*   **Events:** Handling user interactions (e.g., the `input` event on the textarea) to trigger functions that perform calculations and update the display.

## Getting Started
- Open `index.html` in your web browser.
