# Snake Game 🐍
> A classic arcade game re-imagined with modern web technologies.

## Description
This project is a web-based implementation of the timeless Snake arcade game. Players control a snake, navigating a grid to eat food, grow longer, and achieve the highest score without colliding with walls or its own body. It serves as an excellent beginner project for understanding fundamental game development principles directly in the browser.

## Features
*   Classic Snake gameplay mechanics
*   Responsive snake movement controlled by keyboard input
*   Dynamic food generation at random locations
*   Score tracking that increases as the snake eats food
*   Collision detection for game over conditions (walls and self-collision)
*   Game reset functionality to start a new round
*   Simple and intuitive user interface

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Canvas API:** Utilized for drawing the game grid, snake, and food elements dynamically.
*   **Game Loop:** Implemented to manage game state updates, rendering, and animation frames consistently.
*   **Keyboard Events:** Handled to capture player input for controlling the snake's direction.
*   **Collision Detection:** Employed to determine when the snake hits walls or its own body, triggering a game over.
