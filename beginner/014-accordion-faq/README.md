# Accordion FAQ Project #14 🤔
> A simple, interactive FAQ section built with vanilla JavaScript.

## Description
This project implements a classic Accordion FAQ component, allowing users to expand and collapse answers to common questions. It focuses on creating a clean, responsive, and accessible user experience using fundamental web technologies. Ideal for showcasing basic interactive UI development skills.

## Features
*   Expandable and collapsible FAQ items.
*   Smooth transitions for a better user experience.
*   Semantic HTML for improved accessibility.
*   Dynamic content toggling using JavaScript.
*   Clean and modern UI design.
*   Responsive layout for various screen sizes.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)

## Key Concepts Demonstrated
*   **Event Delegation:** Efficiently handling click events on multiple accordion items using a single event listener on a parent element.
*   **Toggle Class:** Dynamically adding and removing CSS classes to control the visibility and styling of accordion answers.
*   **CSS Transitions:** Implementing smooth animations for expanding and collapsing content, enhancing user interaction.
*   **Accessibility:** Ensuring the component is usable and navigable for all users, including those using assistive technologies, through semantic HTML and ARIA attributes.
