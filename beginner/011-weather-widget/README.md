# Weather Widget ☀️
> A simple, elegant web application to display current weather conditions.

## Description
This project is a beginner-friendly web application designed to fetch and display real-time weather information for any city worldwide. It leverages modern web APIs to provide users with up-to-date temperature, humidity, and weather descriptions, offering a quick glance at current atmospheric conditions.

## Features
*   Search for weather by city name.
*   Displays current temperature in Celsius.
*   Shows weather conditions (e.g., "Clear Sky", "Cloudy").
*   Indicates humidity levels and wind speed.
*   Provides clear error messages for invalid city names or API issues.
*   Visually appealing and responsive user interface.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript
*   OpenWeatherMap API (or similar)

## Key Concepts Demonstrated
*   **Fetch API:** Making asynchronous network requests to external APIs to retrieve data.
*   **Async/Await:** Writing cleaner, more readable asynchronous JavaScript code for API calls and data processing.
*   **JSON Parsing:** Handling and extracting relevant data from API responses in JSON format.
*   **Error Handling:** Gracefully managing potential issues such as network failures, invalid user input, or API rate limits.
